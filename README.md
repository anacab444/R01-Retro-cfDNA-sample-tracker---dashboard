#cfDNA QC Analytics Dashboard

##Overview
This project analyzes cfDNA extraction yield and QC metrics using:
- SQL + BigQuery
- Looker Studio
- Clinical cfDNA datasets (de-identified)

## Tools Used
- SQL + BigQuery
- Looker Studio
- Excel
- GitHub

## Key Metrics
- DNA Yield (ng) 
- % samples passing ≥50 ng
- UC500 Sequencing status
- cfDNA Extraction status
